# flags

> A header only CLI arg parser library

### Example Usage
```cpp
#include "flags.hpp"

int main(int argc, char **argv) {

    flags::init("greet", "Greeting App",
                "Enter your name and I will greet you!");

    std::string name;
    bool working = false;

    flags::add("--name", "This is where you enter your name", &name, true);
    flags::add("--working", "This denotes that you are working", &working);

    flags::parse(argc, argv);

    std::cout << "Hi, " << name << std::endl;
    if (working)
        std::cout << "Good luck with your work" << std::endl;

    return 0;
}
```

#### --help output for above code
```sh
❯ ./greet --help
Greeting App
Enter your name and I will greet you!

Usage:
    greet [option] [argument]
    greet [flag]

Options:
    -n, --name <string>       This is where you enter your name (required)

Flags:
    -w, --working             This denotes that you are working
```

#### Output
```sh
❯ ./greet --name Nizal
Hi, Nizal
❯ ./greet -n Nizal -w
Hi, Nizal
Good luck with your work
```

## API Reference

#### `flags::init()`

Initializes basic information about your application for help output

```cpp
flags::init(command, name, info);
```
|Parameter|Type|Description|
| - | - | - |
command | std::string | The name of the binary executable
name | std::string | The name of your application
info | std::string | Brief information about your application

#### `flags::add()`

Register a new argument to parse

```cpp
flags::add(name, info, var, required, alias);
```
|Parameter|Type|Description|
| - | - | - |
name | std::string | Name of the argument
info | std::string | A short description about it
var | std::variant<std::string *, int *, double *, bool *> | A pointer to the variable where the parsed value is to be stored
required* | bool | If this argument must be provided
alias* | std::string | A shorter name for the argument name

*`required` is optional and defaults to false

*`alias` is optional and will be autogenerated if not specified

#### `flags::parse()`

Parses the CLI arguments and loads the values into their registered variables

|Parameter|Type|Description|
| - | - | - |
argc | int | Argument count given to main()
argv | char ** | Argument value array given to main()


> [!NOTE]
> Requires C++17 or later
> `--help` will print the help message. This argument is reserved, and cannot be overridden.
